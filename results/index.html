The BPU is a substrate: same algorithm, float32 vs noisy tiles

Every row compares the same algorithm on a float32 reference and on noisy BPU tiles; success means the tiles match the reference within the stated tolerance. Local learning rules are additional arms, never the headline. Every number is read from results/<e>/results.json; BPU energy numbers are projections from the device model, the GPU control is measured.
